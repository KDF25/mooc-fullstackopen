# Blogs App

Welcome to the **blogs app** — an example application for [Full Stack Open Next.js](https://courses.mooc.fi/org/uh-cs/courses/full-stack-open-nextjs).

## Features

- User registration and login with NextAuth
- Create and browse blog posts
- Personal reading list
- API token for programmatic access

## Getting started

1. Register a new account or log in
2. Create a blog post from the **create new** link
3. Visit your **me** page to manage your reading list and API token
